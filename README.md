# Mini_Generadores_Electricos
Este proyecto tiene como objetivo demostrar de manera sencilla y práctica cómo funciona la energía eléctrica y cómo podemos generarla aprovechando recursos naturales como el viento y el agua.  A través de tres pequeños experimentos, mostraremos cómo la energía puede transformarse para producir electricidad y encender luces LED.

Con este proyecto buscamos aprender sobre la importancia de la energía, conocer diferentes formas de obtenerla y comprender cómo podemos aprovechar los recursos naturales para cuidar nuestro medio ambiente.
